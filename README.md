Aplicación móvil para el seguimiento de niveles de glucosa, desarrollada con React Native (Expo) y SQLite. Permite registrar mediciones diarias con fecha, hora y comentarios opcionales, y consultar el historial completo de registros.
Stack: React Native, Expo, expo-sqlite, @react-native-community/datetimepicker
Features:

Registro de mediciones con fecha, hora y comentario
Historial de mediciones
Persistencia local con SQLite
Distribución via APK (EAS Build)
